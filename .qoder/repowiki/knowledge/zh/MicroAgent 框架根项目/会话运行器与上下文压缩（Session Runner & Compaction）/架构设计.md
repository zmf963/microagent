模块以 `runner.py` 中的 `SessionRunner` 类为编排核心，消费 `LLMClient` 与 `ToolRegistry`，驱动 LLM→工具调用→LLM 的异步流式循环；通过 `budget.py` 的 `Budget` dataclass 构建树形预算结构，子预算通过共享 `anyio.Event` 实现根级取消传播。

- `runner.py`：`run_turn` 是主入口，按预算循环调用 LLM 并处理 `TextDelta`/`ToolCallDelta` 事件；维护 per-session 进程/浏览器状态隔离，支持 `pre_llm_hooks`、`tool_hooks`、`context_sources` 扩展点，并在无工具调用时触发 `MemoryExtractor` 异步提取记忆。
- `budget.py`：`Budget.root()`/`spawn()` 构建预算树，`consume()` 沿父链上报后代用量并在耗尽时抛出 `BudgetExceeded` 异常。
- `compress.py`：`compact_conversation` 统一编排五层压缩——L1 micro_compact（零成本截断可重获工具结果）、L2 snip_tool_results（删除最旧 tool_result）、L3 LLM 结构化摘要（增量更新）、L4 熔断器（连续失败 3 次 + 300s 冷却）、L5 full_dump（关键文件原文转储）。
- `attachments.py`：在 L3 压缩后从原始消息中按最近顺序恢复最多 3 个文件的完整内容作为附件注入，使用正则匹配工具调用参数中的文件路径。
- `search.py`：基于 SQLite FTS5 + BM25 的全局会话搜索，CJK 文本拆分为 bigram，不可用时回退到 LIKE 查询，索引通过 `ensure_fts5(store)` 幂等创建。

依赖方向：向上依赖 `..core.event`、`..core.store`、`..core.tool`、`..core.types`、`..llm.client`，向下通过延迟 import 访问 `..tools.builtins` 中的 browser/process/task/todo_plan_exit 等运行时状态，避免循环导入。
