- 所有异步入口函数使用 `async def` 并返回 `AsyncIterator[Event]` 或 `tuple[...]`，错误通过抛出 `BudgetExceeded` 等特定异常而非返回值传递。
- 对可能引起循环导入的模块（如 `..tools.builtins`、`..memory.extractor`、`.compress`）采用函数内延迟 import，仅在首次调用时加载。
- 资源清理集中在 `close()` 方法中，通过 try/except 包裹确保浏览器页面、内存提取器等外部资源被安全释放。
- 常量集中定义在模块顶部（如 `AUTOCOMPACT_BUFFER`、`MAX_CONSECUTIVE_FAILURES`、`REOBTAINABLE_TOOLS`），并通过类型注释标注 `TYPE_CHECKING` 下的可选依赖。
- 对外暴露的 API 以纯函数或无副作用属性为主（如 `count_tokens`、`micro_compact`、`snip_tool_results`），状态变更通过显式的 `state` 参数传递。
