测试按三层目录划分职责：`unit/` 覆盖核心模块（会话运行器、工具注册、预算控制、持久化、技能加载等）的快速单元测试；`integration/` 通过 `MICROAGENT_TEST_*` 环境变量启用，调用真实 OpenAI 兼容 API 进行端到端验证；`benchmark/` 使用 `pytest.mark.benchmark` 标记性能用例，默认跳过。三层共享 `tests/unit/fake_llm.py` 中的 `FakeLLMClient` 作为 LLM 协议实现，统一模拟流式响应（TextDelta/ToolCallDelta/StreamDone），使单元与基准测试无需网络即可运行。集成与基准测试均通过 `pytest.mark.integration` / `pytest.mark.benchmark` 标记，配合 `pytestmark = pytest.mark.skipif(...)` 实现按需启用。
