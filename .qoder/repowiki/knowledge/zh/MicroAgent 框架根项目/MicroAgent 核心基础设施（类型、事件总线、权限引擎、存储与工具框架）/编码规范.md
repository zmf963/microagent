- 所有核心数据类统一使用 @dataclass(frozen=True, slots=True) 定义不可变且内存紧凑的结构体。
- 面向 LLM 的转换方法统一命名为 to_openai_dict()，直接产出 OpenAI SDK 期望的 dict 格式。
- 工具通过 @tool(name, description=...) 装饰器注册，利用 Pydantic FieldInfo 元数据描述参数，由 _infer_schema_from_signature 自动推导 JSON Schema。
- 异步操作统一返回 awaitable 或 AsyncIterator，EventBus.emit 和 PermissionEngine.evaluate 均通过 try/except 吞掉异常保证调用方不受影响。
- 存储与工具等扩展点通过 typing.Protocol 定义接口（Store、Tool），配合 runtime_checkable 实现结构子类型而非继承基类。
