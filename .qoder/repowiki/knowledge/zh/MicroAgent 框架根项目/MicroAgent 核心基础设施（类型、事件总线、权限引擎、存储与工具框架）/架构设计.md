本模块按职责拆分为五个正交文件，构成 MicroAgent 的基础设施层：
- `types.py`：所有跨组件交换的数据结构（Message、ToolCall、ToolResult、Usage）以及 SessionRunner.run_turn() 产出的 Event 联合类型（TextDelta/ToolCallDelta/ToolProgressDelta/ToolResultDelta/TurnComplete/TurnFailed/SteerEvent），统一提供 to_openai_dict() 以对接 OpenAI SDK。
- `event.py`：纯观察者 EventBus，on/emit 支持同步与异步回调透明混用，异常被吞掉以保证主循环稳定。
- `permission.py`：PermissionEngine 按规则列表自上而下匹配（fnmatch 工具名 + 参数约束），返回 ALLOW/DENY/ASK；ASK 通过可注入的 AskCallback 交由上层交互；ScriptRule 通过 asyncio 子进程调用外部 Python 脚本做决策；DEFAULT_RULES 给出内置工具的默认白名单。
- `store.py`：通过 Store Protocol 抽象持久化接口，SQLiteStore 使用 WAL 模式 + JSON 序列化实现，InMemoryStore 用于单元测试；append/load_history/checkpoint/list_sessions/session_summaries 构成统一 API。
- `tool.py`：Tool Protocol（PEP 544 结构子类型）+ FunctionTool 适配器 + ToolRegistry 管理；@tool 装饰器通过 Pydantic v2 的 create_model/model_json_schema 从函数签名自动推断 OpenAI function-calling JSON Schema；AsyncIterator[str] 返回值自动启用流式 ToolProgressDelta 输出；_default_builtins() 通过导入 builtins 工具触发装饰器副作用完成自动发现。
依赖方向：permission → types；store → types；tool → types；event 独立无依赖。
