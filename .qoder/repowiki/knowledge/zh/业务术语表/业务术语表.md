### 技能 (Skills)
- 定义：MicroAgent 的可插拔能力模块，基于 Claude Code 格式定义，包含 SKILL.md 文件和 YAML frontmatter。支持多源加载（~/.claude/skills、自定义路径）、关键词触发匹配、模糊描述匹配和优先级排序。通过 ClaudeSkillLoader 和 CompositeSkillLoader 管理。
- 别名：SKILL.md、skill loader、ClaudeSkillLoader

### 预算树 (Budget Tree)
- 定义：树形预算管理系统，支持根预算创建子预算（spawn），子代理消耗计入父预算，共享取消事件。当根预算耗尽时自动取消所有后代预算。支持 max_iterations、max_tokens、max_cost_usd 等多维度限制。
- 别名：Budget、BudgetExceeded、root()、spawn()

### 会话压缩 (Session Compression)
- 定义：三层压缩金字塔：micro_compact（智能截断可重新获取工具结果）、compact_conversation（LLM 摘要）、summarize_history（深度摘要）。REOBTAINABLE_TOOLS 集合定义哪些工具结果可以被安全截断（read_file、grep、glob、bash、web_fetch、web_search、context7、browser_snapshot）。
- 别名：compress.py、micro_compact、compact_conversation、summarize_history

### 权限引擎 (Permission Engine)
- 定义：基于规则的权限控制系统，支持 fnmatch 模式匹配工具名和参数约束。Decision 枚举包含 ALLOW、DENY、ASK 三种决策。ScriptRule 允许外部脚本审计工具调用，ASK 回调支持交互式确认。
- 别名：PermissionEngine、Rule、ScriptRule、Decision

### 子代理 (Subagent)
- 定义：隔离的执行环境，具有独立的上下文、过滤的工具集和独立预算。支持 explore（只读代码探索）和 general（多步骤通用任务）两种预设类型。通过 SubagentManager.spawn() 创建和管理。
- 别名：SubagentSpec、SubagentManager、spawn()

### 记忆系统 (Memory System)
- 定义：基于 SQLite FTS5 的全息搜索记忆系统，支持批量写入、全文检索、按相关性评分排序和过期清理。SQLiteMemoryProvider 和 InMemoryStore 提供不同持久化方案。MemoryExtractor 使用 LLM 自动提取和分类记忆。
- 别名：Memory、SQLiteMemoryProvider、InMemoryStore、MemoryExtractor

### 工具注册表 (Tool Registry)
- 定义：工具发现和注册系统，@tool 装饰器声明工具元数据，FunctionTool 封装异步函数调用。支持内置工具（22个）和自定义工具扩展。集成权限引擎和上下文注入。
- 别名：ToolRegistry、@tool、FunctionTool

### 会话运行器 (Session Runner)
- 定义：核心 LLM 循环执行器，管理消息流、工具调用、预算消费和事件分发。支持流式响应、错误处理、资源管理和 ContextVar 会话隔离。run_turn() 方法协程化执行单轮对话。
- 别名：SessionRunner、run_turn()、TurnComplete、TurnFailed

### MCP 客户端
- 定义：Model Context Protocol 客户端实现，通过官方 mcp SDK 连接外部 MCP 服务器，将其工具暴露为 MicroAgent 工具。支持 stdio 传输、工具列表变更通知和 OAuth 认证。
- 别名：connect_mcp_stdio、MCP client

### Cron 调度器
- 定义：基于 APScheduler 的定时任务系统，支持 cron 表达式和间隔调度。CronJob 定义任务名称、调度规则和提示词。CronScheduler 管理任务的添加、启动、停止和会话恢复。
- 别名：CronScheduler、CronJob、schedule
